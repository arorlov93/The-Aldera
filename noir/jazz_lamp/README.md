# Фонарь и саксофон (нуар, 30 с, 9:16)

Ночной город 1940-х после дождя, саксофонист под фонарём. Чёрно-белое изображение с жёстким контрастом,
единственный цвет: янтарный блик на саксофоне. Ролик собирается из кода и привязан к музыке.

## Сборка
```
./build.sh                 # с заглушкой или с вашим audio/sax.mp3
START=3.2 ./build.sh       # если в вашем треке мелодия начинается не сразу
```
Результат: `out/jazz_lamp_1080.mp4` (публикация) и `out/jazz_lamp_720.mp4` (просмотр в телефоне).
Нужны: node + playwright (Chromium), python3 + librosa, ffmpeg.

## Звук
- Положите свой трек в `audio/sax.mp3`.
- **Если файла нет, скрипт ставит временную заглушку**: Kevin MacLeod, «Night on the Docks - Sax»,
  incompetech.com, CC BY 4.0 (тема с 11,85 с). В описании поста тогда обязательна подпись:
  `Music: "Night on the Docks - Sax" by Kevin MacLeod (incompetech.com), licensed under Creative Commons: By Attribution 4.0`.
- Отрезок 30 с: с первой ноты и с собственной концовкой трека (склейка по сходству гармонии, `musicfit.py`).
- Под музыкой тихий дождь и гул города.

## Синхронизация с музыкой (`analyze_audio.py` → `events.js`)
- Склейки планов стоят на долях, ближайших к 2 / 12 / 22 / 27 с.
- Неон JAZZ вспыхивает на сильных атаках мелодии.
- Фары машины проходят мимо музыканта и выхватывают его лицо на пике громкости в окне 22,6–26,4 с.
- Покачивание музыканта и подъём раструба идут по огибающей громкости.

## Структура
| Время | План |
|---|---|
| 0–2 с | Полная темнота, фонарь вспыхивает вместе с первой нотой |
| 2–12 с | Общий план: дождь, отражения, дым в луче, медленный наезд, параллакс (гидрант и капли на переднем плане) |
| 12–22 с | Крупно инструмент: пальцы на клапанах, янтарь латуни |
| 22–27 с | Машина, фары выхватывают лицо: кульминация мелодии |
| 27–30 с | Возврат к первому кадру, фонарь гаснет: ролик бесшовно зацикливается |

## Стек
Сцена: `scene.html` (Canvas 2D, общий нуарный движок проекта), кадры снимаются Playwright, видео собирает ffmpeg.
Remotion (React) здесь не использован: персонажи, саксофон и свет уже написаны на Canvas, а рендер Remotion
делает то же самое (браузер → кадры → ffmpeg). Перенос на Remotion возможен, скилл `remotion-best-practices` подключён.
