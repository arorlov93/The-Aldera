# Категории БАДов на TikTok Shop US: оборот (GMV), топ-товары, цены, насыщенность, формы, динамика 2026

Дата сбора: 01.11.2026. Платные дашборды Kalodata, FastMoss, EchoTik, Shoplus, Tabcut, Charm.io недоступны (пост Kalodata на X вернул HTTP 402). Всё ниже собрано из публичных выдержек: блогов FastMoss, постов Kalodata, статей NutraIngredients, WWD, Nutraceuticals World, New Hope, Revuze, SmartScout. Все цифры трекеров (FastMoss, Kalodata, SmartScout, Charm.io) это оценки по скрейпингу витрины, а не отчётность TikTok. NielsenIQ (NIQ) это панель покупок, у неё другая методика.

Термины:
- **GMV** (gross merchandise value): сумма всех заказов по цене продажи, до возвратов, комиссий и выплат криейторам.
- **Units**: проданные штуки.
- **Выручка продавца**: GMV минус комиссия площадки, комиссия криейтора и возвраты. Ни один источник её по категориям не публикует.
- Если в источнике написано «revenue», а по сути это GMV по витрине, ниже пишу «GMV (в источнике revenue)».

Пометка **[расчёт]** означает мою арифметику по цифрам из источника. **[оценка]** означает вывод без прямого источника, метод указан рядом.
