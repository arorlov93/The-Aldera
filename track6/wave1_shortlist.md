Дата сборки: 2026-09-12. Источник: `creators_db.csv` (390 строк: 274 из транши №1 + 116 из транши №2).

**Что это.** Пятьдесят криейтеров, с которых начинаем посев под первые четыре SKU: магниевые стики для сна, sea moss гаммиз, lion's mane гаммиз, шафран капсулы. Отобраны по: (1) тематическое попадание в конкретный SKU, (2) размер 5k–200k с приоритетом нано/микро, (3) признаки живой аудитории и практики брендовых интеграций, (4) наличие рабочего пути связи, (5) бонус — уже работает в TikTok Shop affiliate.

**Как читать тир.** A — идём первыми, персональный питч под SKU. B — вторая очередь, тот же питч шаблоном. C — держим в резерве волны 2.

**Пометка `IG, сверить TT`** означает: профиль подтверждён в US-рейтинге как Instagram-аккаунт, TikTok-хендл нужно найти перед аутричем. Не писать вслепую.

## Как запускать волну

1. **Порядок.** Сначала 8 действующих TTS-аффилиатов (@milamfamilyfinds, @saleseekerscentral, @nutritiouslyeasy, @momfluencerkatie, @naturallymenolye, @nazyfarnoosh, @modhippiehabits, @theracheldodge) — они знают механику, им нужен только оффер, а не обучение.
2. **Затем** 4 кросс-SKU «этикеточника» — их видео задают тон всей волне и на них потом ссылаются остальные.
3. **Потом** остальные A по SKU, батчами по продукту, чтобы не смешивать питчи.
4. **B-тир** — шаблонным письмом после первых результатов A.

**Дисциплина по заявлениям.** Ни одному криейтеру не отправляем формулировки про лечение, диагностику или профилактику. Угол — состав, дозировка, прозрачность этикетки, личный опыт.

**Перед аутричем обязательно.** Для 4 строк с пометкой «IG, сверить TT» найти TikTok-хендл. Для строк с `unknown`/`nano`/`micro` — снять актуальную численность, чтобы не переплатить за тир.
