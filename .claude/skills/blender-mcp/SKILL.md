# Blender MCP: подключение и работа

Это не обычный скилл, а MCP-сервер: мост между Claude и программой Blender.
Источник: https://github.com/ahujasid/blender-mcp, лицензия MIT.

## Где это работает
- **Только на компьютере, где установлен и открыт Blender.** Сервер подключается к аддону внутри запущенного Blender.
- **В облачной сессии Claude Code это не работает:** здесь нет Blender и нет экрана. Если владелец просит 3D-рендер в облаке, сказать об этом прямо и предложить один из путей ниже.

## Установка на компьютере владельца (делает владелец, один раз)
1. Установить Blender с blender.org.
2. В терминале: `uvx mcp-for-blender setup`. Мастер сам поставит uv, найдёт Claude и установит аддон.
   На Windows без uv: `winget install --id=astral-sh.uv -e`, открыть новый терминал, затем та же команда.
3. Для Claude Code вручную: `claude mcp add blender uvx mcp-for-blender`, затем `uvx mcp-for-blender install-addon`.
4. В Blender: Edit → Preferences → Add-ons → включить «Interface: MCP for Blender».
5. Полностью закрыть и открыть Claude, открыть Blender. Аддон поднимает сервер при запуске Blender.

## Приватность
- По умолчанию автор собирает обезличенную статистику: случайный номер установки, название инструмента, успех и длительность.
- Промпты, код, скриншоты и сцены уходят только если включить согласие в настройках аддона. Не включать.
- Полностью выключить статистику: переменная окружения `DISABLE_TELEMETRY=true` в настройке сервера.

## Как работать, когда сервер подключён
- Инструменты появятся с префиксом `mcp__blender__`. Перед работой проверить, что они есть в списке.
- Сначала запросить состояние сцены, потом менять. Крупные изменения делать шагами и после каждого смотреть скриншот окна.
- Произвольный код Python в Blender выполнять только по задаче владельца. Перед этим сохранять файл сцены.
- Скачивание моделей и текстур из внешних библиотек (Poly Haven, Sketchfab и другие) делать только по просьбе владельца: у них свои лицензии.

## Если Blender недоступен
- Простая 3D-визуализация упаковки: рендер на Python (см. `docs/packaging_2026-10-30/source/render_3x5.py`).
- Подключить компьютер владельца к сессии через Remote Control и работать с его Blender оттуда.
