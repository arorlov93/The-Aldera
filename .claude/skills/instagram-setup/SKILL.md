# Instagram Setup — The Aldera

Контекст бренда: docs/STRATEGY_LAUNCH.md, track5/product_copy.md, track6/tiktok_content_plan.md.
Жёсткое правило клеймов: только structure/function из docs/LABELS_COPY_PACK.md (никаких
болезней/лечения; слова anxiety, insomnia, depression, ADHD — ЗАПРЕЩЕНЫ в постах и bio).

## 1. Профиль (чек-лист оформления)
- Handle: @thealdera (единый с TikTok). Категория: Health/Beauty. Тип: Business.
- Имя в профиле (индексируется поиском): «The Aldera | Magnesium & Wellness» — ключевые
  слова, не только логотип-имя.
- Bio: 3 строки — (1) что мы: Lab-verified supplements, honest doses; (2) социальное
  доказательство/дифференциатор: Scan every bottle → real COA; (3) CTA со стрелкой к ссылке.
- Ссылка: на лендинг/Shopify (НЕ linktree на старте — каждая прослойка теряет 20-30% кликов).
  UTM-метки обязательны: ?utm_source=ig&utm_medium=bio.
- Highlights (5 обложек в бренд-стиле): Products · Lab Results · Reviews · How to Use · FAQ.
- Контакт: email + адрес ISP Group (доверие), WhatsApp-кнопка.

## 2. Контент-система (питается TikTok-конвейером, отдельного производства нет)
- 80% контента = кросс-пост вертикалей из TikTok (Reels), НО: скачивать без вотермарки
  (вотермарка TikTok режет охват Reels алгоритмически).
- Сетка первых 9 постов до запуска: 3 продукт-хиро (упаковка крупно), 3 «наука/честность»
  (COA, дозировки, сравнение с полкой), 3 lifestyle/UGC. Это витрина для криейтеров и
  фабрик — профиль должен выглядеть брендом ДО первых продаж.
- Частота: 4-5 Reels/нед + 2-3 Stories/день (Stories = за кулисами, опросы, отзывы).
- UGC криейтеров репостим в течение 24ч (запрашивать разрешение в DM одним шаблоном).

## 3. Продажи
- IG Shop подключать после Shopify (каталог тянется автоматически через канал Facebook&IG).
- В Reels — стикер продукта; в Stories — link-стикер на лендинг.
- DM-автоответ (слово «ORDER» → ссылка) через Manychat free tier.

## 4. Метрики недели (минимум, без фанатизма)
Подписчики / охват Reels / клики по ссылке (UTM в Shopify-аналитике) / сохранения.
Сохранения > лайков как сигнал алгоритму — контент строить «на сохранить» (гайды, дозы, рецепты).

## Ограничения
- Тексты постов с клеймами — прогонять по запретному списку LABELS_COPY_PACK перед публикацией.
- Розыгрыши с «отметь друга» — не раньше 1k подписчиков, иначе профиль выглядит фермой.
