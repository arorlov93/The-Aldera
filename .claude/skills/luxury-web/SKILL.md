# Luxury Web — как выглядит «дорого» (эталоны: Aesop, Rhode, AG1, Seed, Ritual)

## 1. Скелет люкса
- Тёмное обрамление (хиро/футер) + светлое тело; один драм-акцент на страницу.
- Золото/металлик — только линии, капители, печати. Никогда — заливки больших площадей.
- Сетки ровные: ряд заполняется ДО конца (2-карточные ряды добиваются стек-картой/цитатой), пустых хвостов не бывает.
- Воздух: секции ≥96px, заголовок дышит (≥18px до текста), строка ≤65ch.

## 2. Микровзаимодействия (обязательный минимум)
- Hover карточек: подъём + осветление фото (overlay .9→.65) + тонкий золотой outline.
- Кнопки: hover свечение/яркость, active «вжатие», главная CTA — мягкий пульс.
- Скролл-reveal: секции всплывают 24px/0.7s, ТОЛЬКО ниже первого экрана, respect prefers-reduced-motion, без JS всё видно.
- Липкая шапка появляется после ~600px: бренд + одна CTA, тёмное стекло (backdrop-blur).

## 3. Типографика
- Сериф с характером (Fraunces/Canela-класс) для заголовков, курсивные акценты внутри H2.
- Капители с letter-spacing .2em+ для ярлыков; цифры цен — сериф крупно.
- Айбрау секций: золотая полулиния + капители (фирменный повторяющийся элемент).

## 4. Изображения
- Единая цветовая обработка (наш: тени в зелень, света в золото) — разношёрстный сток убивает люкс.
- Фото-карточки: градиент к низу для текста; hover приоткрывает фото.
- Видео: муди, зациклено, без звука, с типографикой поверх (Coming soon-класс).

## 5. Доверие люкс-класса
- Печати/штампы (ISO-seal), рамки-паспарту (inset border 1px золото), «документные» таблицы.
- Числа и факты вместо эпитетов; один манифест-курсив на страницу.

## 6. Чек-лист доводки (прогонять перед сдачей)
1. Скриншот 1440px и 390px — пустые хвосты рядов? залатать.
2. Каждый интерактив имеет hover И focus-visible.
3. Замечания «слишком тёмный/светлый» решаются лентами фона, не глобальной перекраской.
4. Все клеймы на странице — документируемые (сверка с LABELS_COPY_PACK/COMPLIANCE).
5. Заголовок страницы, OG-картинка и первый экран рассказывают одно и то же УТП.
