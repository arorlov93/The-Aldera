# China Price Scout — разведка цен 1688/Taobao/Alibaba

Прямой доступ к 1688.com/alibaba.com/taobao.com из этой среды ЗАБЛОКИРОВАН egress-прокси.
НЕ пытайся WebFetch на эти домены. Работай только через WebSearch (поисковый индекс).

## Методика (на каждый SKU)

1. Составь 3-4 поисковых запроса, комбинируя:
   - `site:1688.com` + китайское название товара (гуммис = 软糖, стик-пак = 条包/固体饮料,
     капсулы = 胶囊, sea moss = 海藻/爱尔兰苔, магний глицинат = 甘氨酸镁, шафран = 藏红花,
     ежовик = 猴头菇, электролиты = 电解质, грибной кофе = 蘑菇咖啡) + 代加工/OEM/贴牌
   - `site:alibaba.com` + английское название + "price" + MOQ
   - без site: — `1688 <товар CN> 价格 一瓶/一盒`
2. Из сниппетов и заголовков вытаскивай: цену (¥ или $), фасовку (шт/банка/коробка),
   MOQ, имя продавца. Кэш-страницы поисковика допустимы; страницы платформ — нет.
3. Конвертируй CNY→USD по курсу ~7.1 (уточни поиском «USD CNY rate» при первом запуске).
4. Нормализуй к НАШИМ фасовкам: гуммис 60 шт/банка; стики 30 шт/коробка; капсулы 60 шт.
   Если листинг за кг/за 1000 шт — пересчитай и пометь «пересчёт».

## Интерпретация (обязательно включай в вывод)

- Цена 1688 = голый внутренний товар: БЕЗ экспортной упаковки под нас, БЕЗ нашей этикетки,
  БЕЗ COA/FDA-пакета, БЕЗ экспортной наценки. Честная экспортная цена фабрики ≈ 1688 × 1.3-1.6.
  Выше ×2 от 1688 — почти наверняка трейдерская наценка.
- Подозрительно низкие цены на активы (шафран, ежовик) = гардения/мицелий/недовес — пометь.
- Это РАЗВЕДКА, не каталог: точность ±20-30%, для торга этого достаточно.

## Формат вывода

Таблица: SKU | внутренняя цена 1688 (норм. к нашей фасовке, $) | источник-запрос |
экспортный ориентир ×1.3-1.6 | лучшая цена у наших поставщиков | вердикт (норм/переплата).
Строка вывода: у кого из текущих поставщиков наценка выходит за ×2.
Результаты добавляй в track1/china_domestic_prices.md (создай при первом запуске),
коммить и пушь в текущую ветку.

## Ограничения

- Не заказывать и не предлагать заказ через 1688/Taobao напрямую: FDA-товар без документов
  в США не ввозится (см. docs/COMPLIANCE_AUDIT.md).
- Письма фабрикам по итогам разведки — только через согласование текста с владельцем.
