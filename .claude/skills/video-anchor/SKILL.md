# Video Anchor — видео, которое продаёт за 3 секунды

«Якорь» = короткое зацикливаемое видео продукта в действии, которое стоит в хиро лендинга,
первым слайдом листинга и опенером у криейтеров. Опоры: content-factory (хуки/форматы),
landing-builder (куда встаёт), docs/LABELS_COPY_PACK.md (запретные клеймы — и в видео тоже:
ни звука, ни титра с медицинскими обещаниями; † на benefit-титрах).

## 1. Библиотека якорей (по одному на SKU, 10-20 сек, вертикаль 9:16)
1. **Стик → стакан** (магний): рука разрывает стик → порошок сыпется в холодную воду →
   шипение макро → глоток вечером. Эталонная раскадровка — в демо-лендинге (слот play).
2. **Разлом капсулы**: капсулу разламывают над белой/чёрной поверхностью, компоненты
   высыпаются горкой, макро на текстуру + титр «This is what X mg actually looks like».
3. **Гамми-макро**: разрез пополам, текстура, отскок/сжатие пальцами, глянец.
4. **Доза на весах**: порошок на ювелирных весах ровно до цифры с этикетки → титр
   «What we print is what's inside».
5. **COA-ритуал**: скан QR с коробки → отчёт лаборатории на экране телефона рядом с банкой.

## 2. Съёмка владельцем (телефон, 20-30 мин на якорь)
- 4K 60fps (Настройки → Камера), задняя камера, протереть линзу; свет из окна сбоку
  или лампа за кадром; фон чистый (стол + стена), продукт в центре.
- Каждое действие снимать 3-5 дублей ОДНИМ планом без движения камеры (штатив/стопка книг).
- Для шипения/сыпучки — макро: телефон 10-15 см от стакана, фокус тапом ДО начала действия.
- Замедленные кадры снимать в Slo-Mo режиме (240fps) — сыпется порошок, всплеск.
- НЕ монтировать самому — прислать сырьё: каждый дубль отдельным файлом.
- **Передача мне**: залить в Google Drive (папку вижу через коннектор) → написать
  «видео в папке X». Я скачиваю, монтирую, кладу готовое обратно + линк.

## 3. Мой монтажный конвейер (ffmpeg 6.1.1 в системе — проверено)
Рабочая папка: scratchpad/video/. Готовое: track6/video/ (в репо — только финалы <50MB, иначе Drive).
1. **Отбор**: раскадровка каждого дубля (`ffmpeg -i in.mp4 -vf "fps=1,scale=320:-1" f%03d.jpg`),
   выбираю лучшие по чёткости/свету.
2. **Сборка** по битам хука (первые 1.5 сек — самое зрелищное: шипение/разлом, НЕ упаковка):
   trim + concat, джамп-каты каждые 1-2 сек.
3. **Скорость**: разгон рутины `setpts=0.5*PTS`, замедление ключевого кадра
   (slo-mo сырьё или `minterpolate`), speed-ramp на моменте касания воды.
4. **Цвет** («благородная» палитра бренда): `eq=saturation=1.15:contrast=1.06`,
   `curves` тёплые света/зелёные тени, `unsharp=5:5:0.8` для макро.
5. **Титры-хуки**: drawtext, Karla Bold, верхняя треть, появление по таймкодам,
   тексты — из библиотеки хуков content-factory §2, каждый через запретный список, † где нужно.
6. **Финиш**: кроп 1080×1920 (`crop=ih*9/16:ih`), лого-плашка THE ALDERA в конце 1.5 сек,
   `loudnorm` если есть звук; версии: TikTok (звук, 15-25с) / лендинг-хиро (без звука,
   луп 10-15с, `-an`, first frame = лучший кадр) / Amazon (квадрат 1:1, без клеймов вовсе).
7. Экспорт: `libx264 -crf 20 -preset slow -movflags +faststart`, ≤30MB для веба.
8. Владельцу на приёмку — превью-GIF/MP4 в чат (SendUserFile) до финального экспорта.

## 4. AI-генерация (пока нет образцов / для черновиков)
Полноценного видео-генератора в среде нет. Что могу сам: анимированные раскадровки
(canvas, как в демо-лендинге), кинематичные слайд-шоу из фото продукта (Ken Burns:
`zoompan`), анимация этикеток/COA. Фотореалистичный AI-ролик — только внешние тулзы
(Runway/Kling/Pika, $10-30/мес) — решение и оплата владельца; я пишу промпты покадрово.
Правило: AI-видео нельзя выдавать за реальный продукт в листингах — только как
стилизованную графику до прихода образцов.

## 5. Приоритет производства (после прихода образцов YTBIO ~13-15.09)
Магниевый стик (якорь №1, хиро лендинга) → разлом капсулы ashwagandha → гамми sea moss
макро → весы (бренд-манифест, общий для всех SKU) → COA-ритуал. Один якорь = один вечер
съёмки владельца + мой монтаж на следующий день.
