# TikTok Shop Engine — The Aldera

Опоры: track1/competitive_tiktok_dtc.md (механика цен рынка), track1/channel_matrix.md
(роли SKU), track5/tiktok_shopify_economics.md (юнит-экономика), docs/LABELS_COPY_PACK.md
(запретные клеймы — модерация TikTok жёстче FDA; нарушение = бан листинга).

## 1. Ценовая архитектура (закон канала, не обсуждается)
- Якорь (compare-at) $39.95-49.95 → транзакция $22-28 → видимая «скидка 38-50%».
  Так работает весь топ (Toplux: $14.97 от $29.97). Полная цена не продаёт НИКОГДА.
- Пак-сайз TikTok ≠ Amazon (25 стиков vs 30) — решает price parity без демпинга Amazon.
- Flash-каденция: 48-72ч flash ($19.95-21.95) каждые 2 недели на одном SKU по очереди;
  между flash — постоянный «купон продавца» 10-15% (алгоритм любит активные промо).
- Экономика-предохранитель: транзакция не ниже CM $5/ед (см. tiktok_shopify_economics).

## 2. Листинг (карточка = второй лендинг)
- Заголовок: [Результат] + [Форма] + [Кол-во] — "Calm Sleep Magnesium Sticks, Raspberry, 25ct".
- 7-9 изображений: hero-пак → выгоды инфографикой → доза vs полка → COA/lab-proof →
  lifestyle → how-to → отзыв-скрин. Первое видео-слот: лучший UGC криейтера.
- Буллеты — только разрешённые S/F-клеймы с †.
- Отзывы: первые 10-15 = Sample-отзывы через партнёрку (легально в TikTok: отзыв за
  образец с пометкой). Рейтинг < 4.5 душит выдачу — мониторить еженедельно.

## 3. Партнёрка (главный мотор — детали в creator-outreach)
- Open Collab: 20% всем, всегда включён.
- Target Collab: 25-30% топ-50 + бесплатный образец (Free Sample кампании в Seller Center).
- Golden tier: продавцам 50+ ед/мес — 30-33% + эксклюзивный промокод + ранние продукты.

## 4. Spark Ads — единственная реклама (правило из экономики канала)
- Бюджет = 20% TikTok-выручки прошлой недели. Ноль продаж = ноль рекламы.
- Бустим ТОЛЬКО чужие сработавшие видео (Spark-код у криейтера по шаблону запроса),
  никогда не свои студийные. Критерий отбора: органика ≥3k просмотров ИЛИ ≥3 продажи.
- Структура: 1 кампания/SKU, GMV-цель, авто-таргет — алгоритм сам знает покупателя.

## 5. Работа с алгоритмом
- Первые 2 недели листинга = окно раскачки: минимум 10-15 привязанных видео от разных
  аккаунтов (наш @thealdera + криейтеры) — сигнал «живой товар».
- Отвечать на 100% комментариев под shoppable-видео < 4 часов (комменты = ранжирование).
- Live-шопинг подключать после 1k подписчиков магазина — не раньше (пустой лайв вредит).

## 6. Гейтинг и гигиена
- Документы категории: фабричный ISO 17025 COA ≤180 дней + фото этикеток + FDA-рег.
  фабрики + инвойс. Запросы модерации — ответ в 48ч, иначе фриз листинга.
- Никаких слов из запретного списка в видео-скриптах, которые мы даём криейтерам.
