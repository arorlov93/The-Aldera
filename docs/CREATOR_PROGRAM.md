# The Aldera — модель рекламы через блогеров (creator program)

Дата: 27.08.2026. Принцип: **мы не покупаем рекламу у блогеров — мы раздаём лотерейные билеты и доливаем бюджет только в выигравшие.** Фикс-прайс за пост — худшая сделка в этой индустрии; комиссия с продаж + бесплатный продукт — лучшая.

## Почему это главный канал (факты из исследования)
- Sea moss: рынок вырос ×2.7 за год почти целиком на TikTok-криейтерах; #seamoss 1.5B+ просмотров.
- JoySpring (шафран): 6 600+ отзывов в TikTok Shop — путь построен на аффилиатах.
- Toplux (магний): №2 товар всего TikTok Shop US, $14.2M/квартал — комиссионная модель, не фикс.

## Три яруса криейтеров

| Ярус | Подписчики | Что даём | Что ждём | Экономика |
|---|---|---|---|---|
| **Nano** | 1–10k | бесплатный продукт (1–2 SKU) | честный обзор, без гарантий | себестоимость ~$3 + доставка ~$5 = **$8/билет** |
| **Micro** (ядро) | 10–100k | продукт + комиссия 15–20% TikTok Shop | видео с прилинкованным товаром | платим только % с фактических продаж |
| **Mid** | 100k–1M | продукт + 20% + право Spark Ads | 2–3 видео, вайтлистинг | % + бюджет буста ТОЛЬКО после органических продаж |

Фикс-гонорары — нет до месяца 3; исключение: mid-криейтер с доказанными продажами в нашей нише, кап $300–500 и только гибрид (фикс+%).

## Механика по шагам

### Фаза 0 — до запуска (октябрь)
1. **Лонг-лист 300–400 криейтеров**: TikTok Shop Creator Marketplace (фильтры: US, wellness/beauty/foodie, GMV-история) + ручной поиск по хэштегам (#seamoss, #magnesium, #adhdtok, #wellnessroutine, #sleepygirlmokctail). — собираю я.
2. Скоринг: engagement rate >3%, наличие продающих видео (не только лайфстайл), аудитория US.
3. Шорт-лист 150 на посев волны 1.

### Фаза 1 — посев (недели 1–4 запуска)
- **Open Collab в TikTok Shop**: комиссия 15% открыта для всех + **Target Collab**: персональные приглашения шорт-листу с бесплатным образцом и 20%.
- Аутрич-скрипт (DM/email, шлю от имени бренда): короткий, без «мы великий бренд» — «нам нравится твой контент про X, шлём бесплатно наш Y, без обязательств; если зайдёт — в TikTok Shop открыта комиссия 20%».
- Норма: 150 образцов = ~$1.2k. Ожидание по индустрии: 8–15% получивших постят → 12–22 видео.

### Фаза 2 — отбор победителей (недели 3–8)
- Метрика на видео: продажи через линк (видно в Shop-аналитике), CTR, удержание.
- Видео с продажами → **Spark Ads**: просим авторизацию (стандарт в TikTok, криейтеру +бонус $50–100 или повышенная комиссия), заливаем $30–50/день, масштабируем при ROAS ≥2.
- Криейтеры с 2+ продающими видео → «амбассадорский» пул: ежемесячный бесплатный сток, эксклюзивный промокод (даёт их аудитории −10%, нам — атрибуцию вне TikTok: Instagram/YouTube → Shopify).

### Фаза 3 — конвейер (месяц 3+)
- Постоянный ритм: +50–75 новых посевов/мес (пополнение воронки), 10–15 живых амбассадоров.
- UGC-права: у победителей выкупаем права на использование видео в Amazon-листингах и Meta-рекламе ($50–150/видео) — дешевле любого продакшна.

## Бюджет и KPI (первые 90 дней)
| Статья | $ |
|---|---|
| 150 образцов + доставка | 1 200 |
| Spark Ads (только победители) | 2 500–4 000 |
| Бонусы за авторизацию/UGC-права | 500–800 |
| **Итого** | **4 200–6 000** |

KPI: цена опубликованного видео ≤$60 · комиссионные продажи ≥$8k к дню 90 · ≥3 видео с ROAS ≥2 на бусте · смешанный CAC канала ≤$12.

## Compliance-рамка для криейтеров (вкладывается в каждый заказ)
Одностраничный бриф: разрешённые формулировки (supports mood / minerals for skin & hair / supports focus / hydration), запрещённые (лечит/тревога/депрессия/похудение/muscle&sexual — бан категории), обязательное #ad|#commission по FTC. Нарушение = снятие с программы (и риск нашему аккаунту — TikTok банит бренд, не только видео).

## Разделение труда
- **Агент:** лонг-лист, скоринг, тексты аутрича, бриф, аналитика продаж по видео, решения о бусте, отчёт еженедельно.
- **Владелец/VA (~30 мин/день на пике посева):** физическая отправка DM/инвайтов из TikTok-кабинета (площадка не даёт API на аутрич), подтверждение отгрузок образцов.
