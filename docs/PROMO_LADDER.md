# The Aldera — Founding Offers (утверждено к прелончу 10.09)

Три акции до старта продаж (живут на сайте, блок «Founding offers» + секция Pre-order):

1. **Founding Circle — 25% навсегда.** Предзаказ до дня запуска → скидка 25% закрепляется
   на подписочной цене навсегда (пока подписка активна). Лимит: первые 250 founding-заказов.
2. **Launch Week — 20% на всё.** Всем в launch-list: 20% на весь магазин всю неделю запуска
   + ранний доступ за 48 часов.
3. **First Box Perks.** Предзаказ 2+ формул → бесплатная доставка первой коробки + COA партии
   письмом в день публикации.

Правила: акции не суммируются — применяется лучшая. Предзаказ = резервация по email БЕЗ оплаты
(честно указано на сайте); оплата по персональной checkout-ссылке при открытии продаж в октябре.

## Механика предзаказа
- Секция #preorder: чекбоксы 4 октябрьских SKU, живой пересчёт: обычная цена (зачёркнута) vs
  founding-цена (−25%), флаг Free shipping при 2+.
- POST /api/subscribe {email, items[], promo:'FOUNDING25'} → Brevo-контакт с атрибутами
  PREORDER / PROMO / PREORDER_AT + письмо-уведомление «New PRE-ORDER reservation» на info@.
- Октябрьские карточки товаров ведут на #preorder («Reserve — 25% off →»), декабрьские — Notify me.
- В Shopify-фазе: резервациям выслать draft-order-ссылки с прайс-руллом FOUNDING25 (лимит 250
  контролируется вручную по атрибуту PREORDER_AT).

## Экономика (санити)
Магний $24.95 → $18.71 при −25%: маржа сохраняется (~$8-9 CM на юнит при самофасовке).
Подписка −25% = LTV-ставка: удержание важнее первой маржи. Лимит 250 ограничивает риск.
