## 5. Cash conversion cycle (ТЗ п.19)

Депозит 40% (день 0) → баланс 60% (день ~25, после инспекции) → прилёт (день ~32) → продажи (день ~40) → **первый Amazon payout (день ~55–60)** → полный возврат кэша партии при базовом темпе — день ~150–170. Ресток победителей финансируется ЧАСТИЧНО из выручки декабря + резерв Safe-модели. Правило: **депозит партии №2 нельзя планировать из payout'ов партии №1 раньше дня 75.**

## 6. Reorder point — формула вместо «50%» (ТЗ п.20)

RP = daily_sales × lead_time(45 дн: 20 произв. + 18 море + 7 приёмка) + safety stock (21 день продаж) = **units/day × 66**.
Пример: локомотив 15/день → RP = 990 шт → при старте с 1200 перезаказ уходит через ~2 недели продаж. Вывод: **депозит партии №2 по победителям — практически сразу после первых стабильных недель, это заложить в кэш-план.**
