## Почему Флорида, а не Вайоминг (решение)

Ты живёшь во Флориде и ведёшь бизнес оттуда → LLC из Вайоминга всё равно пришлось бы регистрировать во Флориде как «foreign LLC»: платишь дважды (WY: ~$60/год + registered agent $50–125/год, плюс FL foreign registration $125 + annual report $138.75). Выгоды ноль: во Флориде и так **нет налога штата на доходы физлиц**, LLC — pass-through. **Вывод: открываем Florida LLC напрямую.** Вайоминг имеет смысл только без физического присутствия в каком-либо штате — не наш случай.

## Сразу после регистрации LLC

1. **EIN (IRS):**
   - Есть SSN/ITIN → irs.gov «Apply for EIN Online», 10 минут, бесплатно, номер сразу.
   - Нет SSN → форма **SS-4** по факсу IRS (+1-855-641-6935), в строке 7b пишется «Foreign», срок 1–4 недели. Заполненную SS-4 подготовлю — нужен только ответ, есть ли SSN.
2. **Банк:** Mercury (основной, онлайн, нужны Articles + EIN) + Wise Business (платежи фабрикам в Китай). Подготовлю данные для анкет.
3. **Operating Agreement** (внутренний документ, банки иногда просят) — драфт single-member OA подготовлю сам, подпишешь.
4. **BOI-отчёт (FinCEN):** проверю актуальные требования на момент регистрации — правила менялись в 2025; если требуется для новых LLC, подготовлю подачу (бесплатно).
5. **TM «LUCERE» (USPTO, класс 5)** — заявка TEAS Plus $250, подготовлю после knockout-поиска.
