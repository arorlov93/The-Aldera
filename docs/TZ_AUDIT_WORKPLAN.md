## Позиция агента по ключевому вопросу ТЗ («какой SKU первым»)
Согласен с логикой hero-first по маркетингу, но НЕ по закупке: пробная партия 5k и есть механизм выбора героя — она дешёвая ($11.3k landed), а данные реальных продаж надёжнее любого прогноза. Решение: закупаем 5–6 SKU ВЗВЕШЕННО (не поровну), но **запускаем последовательно**: маркетинговый бюджет первых 4 недель концентрируется на №1–2 (sea moss + магний), остальные листинги живут органически как каталог и «второй товар в корзине». Партия №2 — уже только победители ×3 объёма. Так совмещаем hero-стратегию с портфельной проверкой за те же деньги.
