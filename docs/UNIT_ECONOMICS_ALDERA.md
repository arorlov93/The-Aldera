## 3. Как выстраиваем рекламу

### Логика системы: TikTok создаёт спрос → Amazon его собирает
Покупатель видит продукт в TikTok → половина покупает там же, вторая половина идёт искать бренд на Amazon. Поэтому запуск каналов синхронный, бюджет делится, брендовый поисковый трафик на Amazon защищаем с первого дня.

### TikTok Shop — двигатель (месяцы 1–3)
1. **Аффилиаты, не свои ролики.** Открываем affiliate-план 15–20% + бесплатный образец. Рассылаем 100–150 образцов микро-криейтерам (10–100k подписчиков, ниши wellness/beauty/adhd-focus). Математика: образец стоит нам ~$3 landed+ship; 1 из 10 криейторов делает продающее видео — это дешевле любого CPM.
2. **Spark Ads** только поверх видео, которые уже продают органически: $30–50/день на видео, масштабируем то, что даёт ROAS ≥2.
3. Compliance-рамка: только «supports mood / minerals for skin & hair / supports focus» — формулировки из одобренного списка Трека 2, никаких болезней/похудения.

### Amazon — сборщик (с первого дня листинга)
1. **Запуск (недели 1–4):** Sponsored Products auto + exact по 15–20 ключам категории; бюджет $50→150/день по мере данных; купон −20%; **Vine** (30 юнитов) для первых отзывов. Целевой ACOS запуска 40–60% — это цена входа в органику, покрывается маржой 64%.
2. **Стабилизация (месяцы 2–4):** отсев ключей до ACOS ≤30%, брендовая кампания (защита «aldera»), Sponsored Brands на бандл. Целевой TACOS 12–15%.
3. KPI-гейт из промта: маржа ≥35% при рекламе 20% выручки — модель держит его с запасом ($19.10 CM − $6.00 ads = $13.10 = 44%).
