## ЖЁСТКИЕ ОГРАНИЧЕНИЯ (COMPLIANCE — нарушать нельзя)

1. Только **structure/function claims**: supports focus / mental clarity / cognitive function / healthy memory / calm focused mind / mental sharpness / brain health / nootropic support.
2. **Запрещены disease-claims во всех каналах** (этикетка, Amazon, TikTok, email, лендинги, ответы на отзывы): treats/cures/prevents, Alzheimer's/dementia, anxiety/depression/ADHD, «reverses cognitive decline», «clinically proven» без собственного исследования. Риск = FDA/FTC warning letter.
3. Где есть claim — **дословный дисклеймер FDA**: «This statement has not been evaluated by the Food and Drug Administration. This product is not intended to diagnose, treat, cure, or prevent any disease.»
4. Перед печатью этикетки и запуском рекламы — `LEGAL REVIEW REQUIRED`: финальные тексты показать FDA/FTC-консультанту (найди 2–3 кандидатов и запроси цены — тоже твоя задача).
5. В контенте: никаких before/after медицинских состояний. Разрешённые углы: личный опыт фокуса, fruiting body vs mycelium, верификация QR→COA, «calm-focus morning stack».
6. **Письма от имени бренда:** только правдивые факты (бренд на стадии запуска — не выдумывать «5 лет на рынке»), деловой тон; крупные обязательства (заказы, оплаты, контракты) — только после подтверждения владельца.
